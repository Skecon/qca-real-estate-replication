# Source material

The two PDFs this replication was written against are **not committed** — the
article is published by Elsevier and is not ours to redistribute.

Place them in this folder to follow along with the equation references used
throughout the code and notebooks.

## The paper

> I-Cheng Yeh and Tzu-Kuang Hsu (2018). "Building real estate valuation models
> with comparative approach through case-based reasoning."
> *Applied Soft Computing* **65**, 260–271.
> <https://doi.org/10.1016/j.asoc.2018.01.029>

Save as `docs/paper/02 paper 2018.pdf`.

Every equation number in this repository (Eq. 8, Eq. 25, Eq. 32, …) refers to
this article.

## The dataset documentation

> UCI Machine Learning Repository, *Real Estate Valuation* data set.
> <https://doi.org/10.24432/C5J30W> · <https://archive.ics.uci.edu/dataset/477>

Save as `docs/paper/01 data - about.pdf`.

## The data itself

`data/raw/Real estate valuation data set.xlsx` **is** committed. It is released
by UCI under a Creative Commons Attribution 4.0 International licence, which
permits redistribution with attribution. It holds the 414 Sindian transactions
— one of the four circles of supply and demand the paper studies.
